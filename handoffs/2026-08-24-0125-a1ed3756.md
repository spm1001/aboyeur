## For Claudes to come

When a primitive offers a judge, ask which HALF of review it carries. Review is two jobs wearing one name: the verdict (is this actually done?) and the remedy (fix what's fixable, steer what isn't). Measured on CC 2.1.241: /goal's evaluator and Workflow's judge stages carry only verdicts — the evaluator has no tools at all, and its real power is re-engagement (it re-prompts the doer with the not-met reason, which defeated a premature stop in the live test). Nothing evaluator-shaped writes a fix; remediation always needs a session-shaped role with tools (a Workflow stage, an Agent subagent, a real session). Corollary for any escalation-by-convention protocol: a phrase greps as mention, not use — "No human review needed" fires a case-insensitive substring check for HUMAN REVIEW NEEDED, which is conductor.sh's own latent bug, caught the first time the ported protocol ran for real. Reserve an anchored token (line-start, colon, case-sensitive) and tell the roles the phrase is never written except to mean it.
